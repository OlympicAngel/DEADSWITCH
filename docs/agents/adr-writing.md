# Playbook: Writing an ADR

Write an ADR when a decision is expensive to reverse: engine, save format, event schema, network protocol, monetization plumbing, dependency choices.

- File: `docs/adr/NNNN-short-title.md`, next number in sequence. Copy `0000-template.md`.
- Status: Proposed -> Accepted -> (Superseded by ADR-XXXX). Never delete; supersede.
- Keep it to one page: Context, Decision, Consequences (good and bad), Alternatives considered.
- Link it from `docs/adr/README.md`.
